How to practise

  1. Pick a formula and watch its demo.
  2. Look at the dataset (section 2) — note the column letters and the task row.
  3. Type the formula in the practice box — use the column letters from the table.
  4. Press Check answer. Wrong? Read the error, then press Show solution.
  5. Switch datasets and try the same formula again — the task row and the answer change with the data.
  6. Big file? The table shows 50 rows at a time — use Previous / Next below it. Formulas always use every row. Download any dataset as CSV (button above the table) to practise in real Excel.
